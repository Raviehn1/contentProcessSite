Platform integration

Pinterest Integration

ContentProcess connects content-production workflows with publishing and promotional channels. The Pinterest integration is designed around the official Pinterest API and Pinterest authorization mechanisms.

Purpose

An authorized user can include Pinterest in an individually configured ContentProcess workflow, for example to prepare, create, manage or publish Pins and related content as part of a broader product-content process.

Official authorization

Access to a Pinterest account occurs only after the user explicitly authorizes ContentProcess through Pinterest's official OAuth flow. ContentProcess does not ask users to provide Pinterest passwords to the application.

User control

Actions are driven by user-configured workflows and operate only within permissions granted by the user. Connected-account access can be revoked through the relevant platform controls.

Data handling

Pinterest data is processed only as needed to provide the requested integration functionality. ContentProcess does not sell personal data obtained through the Pinterest integration. See the Privacy Policy for more information.

Deletion

Integration-related deletion requests are described on the Data Deletion page.

Support

Questions about the integration, permissions or app review can be directed through the Contact page.
